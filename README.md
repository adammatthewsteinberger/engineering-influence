# engineering-influence

`engineering-influence` is a generic, autonomous content-engineering pipeline.
It turns a project with governing postulates into durable, reviewable artifacts through
ordered phases, typed gates, bounded runners, and recoverable queued work.

The public project contains the method and pipeline software only. Author-owned books,
profiles, and private publishing configuration live in the separate `books` repository.

## Status

The repository is being rebuilt from an orphan FOSS history. The first release establishes
the domain and port boundaries; integrations are added behind those ports.
