Webhooks work end to end. With `EI_WEBHOOK_URLS` set to `https://` receivers, the worker queues an event with each run's state change (`pipeline.started` when a run starts, `phase.completed` as each stage finishes, `gate.awaiting` when a spend decision is needed, and `pipeline.completed` at the end), and delivers the queued events on a loop (`EI_WEBHOOK_INTERVAL_SECONDS`, default 5). Each delivery is signed with `EI_WEBHOOK_SECRET`, which is required when receivers are set and is never printed. Failed deliveries are retried and dead-lettered after five attempts. With no receiver set, nothing is queued or sent. A failed run sends no event, since the catalogue has no failure event. Compatible: three new settings and the webhooks page; the event catalogue and envelope are unchanged.
