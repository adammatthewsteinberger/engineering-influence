The default is now free (M6.6): with `EI_STAGE_EXECUTOR` unset, a run's stages are written by `gpt-oss:20b` (Apache 2.0) on your own machine through Ollama, with a SearXNG at `http://127.0.0.1:8888` for research, no key and no cost. It was chosen by running the installed candidates on one 24 GB laptop over three book-copy tasks, which is a small test; see `docs/LOCAL_MODEL.md`. `EI_LOCAL_MODEL` and `EI_LOCAL_URL` point at another model or server; `EI_STAGE_EXECUTOR=model` still means a model of your own with a profile and a price, and `deterministic` the offline placeholder, which the example compose stack now sets because a container cannot reach the host. A profile may set `reasoning_effort` (`low`, `medium`, `high`) for an openai_compatible server, so a model that reasons does not spend a stage's whole token cap before it writes. Building the executor contacts nothing, and `ei doctor` does not yet check the local server, the model or its context size.
