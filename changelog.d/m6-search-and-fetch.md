Research sources can now be found and read. `BraveSearchProvider` runs a web search and keeps only each result's link and title. `HttpSourceFetcher` reads a page as evidence: the outbound URL policy is asked before the first request and before every redirect, only HTML and plain text are accepted, a body over the size cap is refused (compressed bodies are not accepted, so a small download cannot expand in memory), and no cookies or credentials are sent. `HtmlTextExtractor` keeps what a reader would see and drops scripts, comments, hidden elements and invisible characters, so a page cannot hide instructions from the reader. Nothing uses them yet, and neither the search adapter nor the fetcher has been run against the live internet.
