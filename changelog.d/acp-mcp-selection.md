An Agent Client Protocol session may select MCP servers in session/new, but only by name: each name must be a server the operator's lock already has, so a client cannot start a command or contact a URL the operator has not locked. The selection is stored with the session (migration 0003) and restored by session/load. Connecting the selected servers to the run, with their sandbox and an approval, is a later change. Compatible: a session with no servers is unchanged.
