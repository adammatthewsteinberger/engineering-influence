Groundwork for a screenplay's bible: a bible folder of TOML cards (ADR 0018) is read and checked as a whole before a run uses it. Each subfolder is a kind and each Markdown file a card, whose front matter sits between `+++` lines. `bible.toml` may name the keys each kind requires. The check refuses a duplicate id, a `[[kind: id]]` link to no card, and a real person (`real = true`) with no clearance or with a likeness or voice. Nothing reads the bible into a run yet; that follows with `--bible`. Compatible: no existing behaviour changes.
