There is now a way to try the whole non-fiction pipeline against a real model, with a spending limit you set in advance. `tests/paid/test_live_smoke.py` is a `paid` test (it never runs by default and refuses to start without `EI_ALLOW_PAID=1`) that drives all eleven stages in one process with in-memory adapters, so it needs no database, queue or worker. It requires `EI_SMOKE_BUDGET_MICRO_USD`, which has no default, uses a made-up author, and writes every artifact and a `smoke-report.json` (per-stage outcome, attempts, cost and time) to a folder even when the run fails. The same driver runs in the normal suite against a scripted local server, as a free rehearsal of the chain, the retry loop and the budget stop. See `docs/LIVE_SMOKE_TEST.md`. Nothing here has yet been run against a live model; that is for you to do with your own key.
