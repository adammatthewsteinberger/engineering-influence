A revision's pages name the revision and its date on the title page, for example `Revision: Pink (2026-11-27)`. `book create --previous-script FILE --revision N --revision-date YYYY-MM-DD` sets the date; without it the date is today's. The date is kept with the run, so a resumed run prints the same one. A date that is not YYYY-MM-DD is refused before anything is saved, with `RUN_REVISION_DATE_INVALID`. Compatible: the date is optional; a run without a baseline is unaffected.
