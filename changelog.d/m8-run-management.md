Book runs can be listed, resumed and cancelled over the API, MCP and the SDK (M8.4): `GET /v1/runs`, `POST /v1/runs/{run_id}/resume` and `POST /v1/runs/{run_id}/cancel`, the `list_runs`, `resume_run` and `cancel_run` MCP tools, and the matching SDK methods (sync and async). They go through one `RunManagement` service that composes the list, resume and cancel services the command line uses, so every surface refuses what the command line refuses: an unknown run is `404`, a finished run cannot be resumed (`409`). A parity test checks each surface against the services, including the refusals and the missing-key case.
