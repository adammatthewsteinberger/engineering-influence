A screenplay run now has two revision passes after the scene revision. A structure pass (`structure_scenes`, prompt `screenplay_pass_structure`) makes each scene's card happen on screen and turn toward its next beat. A dialogue pass (`dialogue_scenes`, prompt `screenplay_pass_dialogue`) cuts lines that explain what the audience can see and keeps the lines that carry the plot. Each pass keeps the model's answer only when it passes the same section check and length rule as the revision; otherwise the scene carries forward unchanged, and when the money runs out the rest carry forward. The assembled script reads the dialogue pass's output. The format pass is the existing Fountain format check on the assembled script, so it is unchanged. Compatible: the two stages and their prompts are new, and no command, error code or issue code changed.
