Removed the last nine test patches of production code by passing the collaborators in through constructors, so no test patches a production class any more; the only patches left are standard-library calls at the system boundary and one class a test defines itself. `PublishingController` and `PublishSteps` now receive a `BookBuilderInterface` and a `PdfVerifierInterface` instead of building `BookBuilder` and `PdfVerifier` themselves, and the controller no longer takes the LaTeX compiler, build workspace and package assets that only existed to build the book builder. `PublishingControllerFactory` builds each once and gives the same instance to the controller and to `PublishPipelineProvider`. `CoverBuilder` takes optional image, ebook and print-PDF verifiers, and `EbookCoverVerifier`, `PrintPdfVerifier` and `CoverRenderer` take KDP's size and text limits as constructor arguments that default to `KdpCoverSpec`, so a test passes a tiny limit instead of editing the spec. `ApiRuntime` takes an optional queue, and `ServeStarter` takes optional runtime factories for its default runners; its imports stay lazy.

Every default is the previous behaviour, and none of these classes is part of the public API. The generated REST schema, the MCP tool list, every `ei` help page and the wheel's file list are unchanged. Not every pure helper is injected yet: the controller still builds the audit classes and `EpubVerifier` still builds its own checks, because no test has to replace them. The architecture test now lists only the system boundary, and its two tests are renamed to match (`test_tests_patch_only_the_system_boundary` and `test_the_boundary_list_has_no_stale_entries`).
