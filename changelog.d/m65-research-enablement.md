`ei doctor --search` runs one real search through each configured provider (SearXNG, then Brave when its key is set), one at a time so a down SearXNG is not hidden by Brave behind it, and prints a line each: how many links came back and the host of the first (never a title or address from the web, and a host with a control or unusual character is replaced by a placeholder). It takes `--query` (the default is the harmless sentence `open source book publishing`; the query leaves the machine) and runs on its own, not with `--models`. Exit 0 all answered, 1 one did not or nothing is configured, 2 the setting is unusable. New `docs/RESEARCH.md` covers search setup, installing your own methodology skills for the research stage (`ei skills import --reference`, `ei plugins import`), and what is not built. The live smoke test's setup now points at the check. The check itself has only been run against local servers written for the tests, not a live SearXNG instance or Brave.
