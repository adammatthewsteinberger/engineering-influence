A skill can now carry **reference sections** that the model reads on request instead of having them in every prompt. A skill file may have a `[reference]` table of `"Section title" = "text"`; a stage the skill is enabled for gets an index of the sections (a line each, with its length) and the built-in read-only `read_skill` tool, and the model names a skill and a section to get its text, returned as untrusted tool output. `read_skill` refuses any skill or section the calling stage's own prompt does not list, so a skill enabled for one stage cannot be read from another. A section may be up to 20,000 characters, a skill 64 sections and 200,000 characters; a skill file may now be up to 256 KiB. `ei skills import --reference` keeps the sections of a `SKILL.md` for this (no `--stage`), so a long methodology reference imports whole. The drafting and editing passes are offered the tool too. The skill guidance template is now version 2, so prompt versions of stages with skills change. Nothing here has run against a live model.
