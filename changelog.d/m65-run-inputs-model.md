A book brief can now carry **inputs**: up to eight blocks of plain text (notes, an excerpt, reference material), each named, at most 50,000 characters and 200,000 in all, stored with the run. Brief version 1 gains an optional `inputs` list, so every existing brief reads the same, and a run stored before this loads with none. Text with a control, format, private-use or invisible character is refused, never cleaned. A `FileRunInputReader` reads a `.txt`, `.md` or `.markdown` file of UTF-8 text up to 256 KiB through no link. Inputs are untrusted data and grant nothing (ADR 0011). **Nothing uses them yet**: no command starts a run before `ei book create`, and the stage prompts do not carry inputs until the next change.
