A screenplay run can now start from an earlier run's shooting script lock. `ei book create --kind screenplay --previous-lock FILE` reads the earlier run's `shooting_lock.json` and keeps it in the new run as `previous_shooting_lock.json`, and the lock stage plans from it, so every scene keeps its number. A lock given to another kind of run, or to a build that cannot keep run files, is refused before anything is saved. Compatible: the command tree gains one optional flag, `--previous-lock`, and no existing command, code or stage changed.
