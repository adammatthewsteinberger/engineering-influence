A book run can now stop after a named stage. `ei book create --stop-after STAGE` ends the run after that stage and runs nothing after it, so a screenplay can be made as far as its scene cards without drafting the scenes. A stage the kind of run does not have is refused before anything is saved, with `STOP_STAGE_UNKNOWN`. Compatible: the flag is new and optional, the new error code is additive, and a run without the flag is unchanged.
