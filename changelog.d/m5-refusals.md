Added `AskModel`, the policy a stage uses when a model's answer is not complete, and `ModelAnswer` (the text, whether it is complete, the issues, the cost and the number of calls). An answer cut off at its output cap is asked again with the cap doubled, up to the model's own limit; a refusal is asked again, identical and never reworded, up to a bounded number of times (default one retry); when the attempts run out (default four calls) the best text found comes back with a blocking `TRUNCATED` and/or `REFUSED` quality issue and the stage carries on. Before any live call it replays a complete answer at any output cap it could have reached, so a resumed run does not pay again for the attempts that led to an answer it already has, and every call is journaled under its own attempt number so no cost is lost. Running out of money and provider failures pass through to the run unchanged. `CallModel` gained `replay`, which looks up a complete answer for nothing. See `docs/MODEL_CALLS.md`.
