Gave every class in `errors/`, `models/` and `contracts/` an interface: 45 new `…Interface` modules, each beside its class in the layer's `interfaces/` folder, and each class now inherits its own. The interfaces declare methods only (never fields, so dataclasses, pydantic models and exceptions behave exactly as before), set `__slots__ = ()`, and import models and contracts only for type checking. The four enums (`GateKind`, `JobOutcome`, `PhaseState`, `PipelineStage`) get `runtime_checkable` Protocols instead, because an enum cannot inherit an ABC, and a new architecture test checks every member against its Protocol. The generated REST schema, the MCP tool list and every `ei` help page are byte-identical.

The 27 existing interface modules now follow the same rules: each declares `__slots__ = ()`, and the 11 that imported a model or contract at runtime import it for type checking only. That removes the last six layer-crossing imports, so the layer-crossing ratchet and the interface-rule ratchet are both at zero.

Renamed the gate-evaluation port `GateInterface` to `GateEvaluatorInterface` (module `engineering_influence.interfaces.gate_evaluator_interface`), so that `GateInterface` can be the interface of the `Gate` model. Code that subclasses or imports the port by its old name must use the new one; like the earlier `*Port` renames, there is no alias.
