Moved the last 19 classes of `engineering_influence.publishing` into the layers: page QA into `models/qa` (`PageRecord`, `RenderReport`, `PageFileNumber`) and `infrastructure/qa` (`RenderQa`, `PageRasterizer`, `BlankPageDetector`, `ContactSheetBuilder`), and release evidence into `services/release` (`PublishPipeline`, `PublishSteps`, `FormatPolicy`, `ReleaseSummary`, `PageLimitCheck`), `repositories/release` (`ArtifactInventory`, `FileDigest`, `JsonReport`, `StepRecorder`) and `infrastructure/release` (`GitState`, `ToolVersions`, `EpubZipCheck`). The bundled LaTeX classes, stylesheets and fonts moved to `infrastructure/publishing/assets/` beside `PackageAssets`, which finds them; a wheel still ships all 17 files.

`PublishPipeline` and `PublishSteps` no longer read the clock, run git, open archives or build their own helpers: they take `ClockInterface`, `RenderQaInterface`, `ArtifactInventoryInterface`, `JsonReportInterface`, `StepRecorderInterface`, `GitStateInterface`, `ToolVersionsInterface`, `EpubZipCheckInterface` and `EpubVerifierInterface` arguments, and read PDF page counts through `PdfInspectorInterface`. `PublishingController` takes a `RenderQaInterface` and a `PublishPipelineProviderInterface`; a new `PublishPipelineProvider` in `runtime/` builds the pipeline when `publish` starts, so cover plugins still load at that moment, even for `--audit-only`. With that the controller imports nothing from the old `publishing/` package, and the temporary import-linter exceptions for it are gone: all three contracts pass with no ignored imports. `BuildWorkspaceInterface` gained `ensure_tree`.

One visible detail: when `ei book` runs without the `publishing` extra, the error still says how to install it and names the first missing library, but which library that is can now differ (for example `markdown_it` instead of `PIL`), because the controller no longer imports Pillow first. The `ei` commands, their output and the reports they write are otherwise unchanged.
