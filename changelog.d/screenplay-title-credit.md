A film's title page can now carry a credit line and a source book, each set per film. The author puts an optional `title.toml` in the `--source` folder with `credit` and `source` as text, one line each, at most 200 characters. The file's other keys are refused by name, so a typo cannot silently drop a line. Compatible: the file is optional, and a run without one prints the title page it always did. The file is read from the source folder only; the source intake still reads only `.md` and `.txt` files, so it is never mistaken for a source.
