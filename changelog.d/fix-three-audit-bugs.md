Three bugs found by the documentation audit are fixed. An unknown pipeline stage is now refused where every interface validates the request: `POST /v1/pipelines` answers 422 naming the real stages (the audit read it as a 500 before), and `ei pipeline start --stage` rejects it as a usage error instead of printing a traceback; a blank `--slug` or `--title` is likewise one line and exit 2. `ei book create` now checks that `--out` is a new or empty folder before any stage runs, where it used to find out only when writing the book at the very end; when resuming into a folder that already holds an earlier export it says how to continue into a new folder with `--state-dir`. `ei doctor --ready` runs each of its parts on its own, so a part that cannot start (a missing extra, an unusable setting) is one failed line and no longer hides the others, and it skips the local model, saying so, when `EI_STAGE_EXECUTOR` is not `local`.
