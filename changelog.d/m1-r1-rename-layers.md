Renamed the `domain` package to `models`, the `interaction` package to `interactions`, and the 20 `*Port` interfaces to `*Interface` (modules `*_port.py` become `*_interface.py`). Code that imports `engineering_influence.domain`, `engineering_influence.interaction` or a `*Port` class must switch to the new names. The `ei` command, the REST API, the MCP tool, the SDK and the cover-plugin API are unchanged, and no behaviour changed: the OpenAPI document, the MCP tool list, every CLI help page and the wheel contents match the previous build apart from these paths.
