The documentation site's tables are fixed. The Vibey stylesheet keeps every table cell on one line and leaves the text colour of the odd rows unset, and the site's own stylesheet broke code at any character, so a table such as "What you get" showed black text on a dark background in alternate rows and a first column one letter wide. Every row now takes the table's own text colour, cells wrap their prose, and a wide table scrolls inside itself. Checked in a browser on all 44 pages: no dark cell and no horizontal page overflow. A test pins the rules so a stylesheet edit cannot bring it back.
