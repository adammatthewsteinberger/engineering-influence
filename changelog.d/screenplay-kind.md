Groundwork for automated screenplays: the `screenplay` book kind exists in the enum, and its source is read from a folder of Markdown and text files (ADR 0017). Each file becomes a numbered, digest-pinned source; an empty or missing folder, a file over 2 MB, and a file with control characters are refused. Screenplay runs are not yet available: `ei book create --kind screenplay` is refused as unsupported until the plan's later pull requests land. Compatible: the new kind value and three error codes (`SOURCE_EMPTY`, `SOURCE_FOLDER_MISSING`, `SOURCE_TOO_LARGE`); no existing kind changes.
