Marketplace indexes (ADR 0008, slice 6b). A marketplace is only an index: a TOML file listing plugin files, each with an address and the SHA-256 the file must have, with no other key. `ei plugins search INDEX [TEXT]` lists its plugins, and `ei plugins fetch INDEX NAME [--output DIR]` downloads one, **checks its hash against the index's before reading it as anything**, checks that it is the plugin and version listed, and saves it as `NAME.toml` without overwriting anything. **Fetching installs nothing**: it prints the `ei plugins show` and `ei plugins add` commands to run next, so installing stays an offline step on a file a person has read. `INDEX` is a file on disk or an `https://` address. A download goes through the same pinned-address URL policy as `fetch_url` and the remote tool transport (https, a public address checked each time, the connection made to the address that was checked, no redirects, no cookies, no compression, 512 KiB and 30 seconds); an address in an index has no user, password, query string or fragment. A run never contacts a marketplace, and only `search` and `fetch` can use a network. The downloader needs the `runtime` extra and is built on first use, so the core install still runs every other command and a local index file. Indexes and plugin files are not signed: the hash proves only that the bytes are the ones the index described. See docs/PLUGINS.md.
