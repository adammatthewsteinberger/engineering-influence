Added the prompt library. A prompt is now a `PromptTemplate`: named text parts with `{{blanks}}`, a whole-number version, and a list of blanks that take text from outside. Rendering is strict (every blank given, nothing extra, values never re-expanded), and text from outside is always wrapped in an `<untrusted>` block with any copy of that tag inside it defused; a template may not put such a blank in its `system` part, and must have a `system` part that says how to treat it. `TomlPromptLibrary` loads `templates/*.toml` from the package behind a `PromptLibraryInterface` port, and refuses unknown keys. The context assembler now takes its section labels from the shipped `context_pack` template, and records `context_pack@1` as the prompt version (the prompt text itself is unchanged). A lock test pins each template's version to a fingerprint of its text, so a prompt cannot be edited without a version bump (the version is part of the journal key, so an edit under an old version would replay answers written for the old text). The templates ship in the wheel and load in a bare install. See `docs/PROMPTS.md`.
