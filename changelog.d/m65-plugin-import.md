`ei plugins import FOLDER` turns a Claude Code plugin folder into a plugin bundle to review, then install with `ei plugins show` and `add`. It reads `.claude-plugin/plugin.json`, `.mcp.json` and `skills/*/SKILL.md`: each skill becomes a reference skill (enabled for no stage), and a server is kept only if the tool lock would accept it (an absolute, non-launcher command, or an https address). Placeholders are not expanded; environment values and headers are not copied, only variable names and a `Bearer ${NAME}` token as `bearer_env`. Commands, agents, hooks and the like are named and set aside, never read or run, and every skipped server or skill is printed with its reason. The file is written new, named for the plugin, and parsed again before it is written. Nothing has run against a real Claude Code plugin from the wild beyond the shape of the files.
