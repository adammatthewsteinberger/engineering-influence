A screenplay's scenes are drafted by the model. The new `screenplay_draft_scene` prompt writes one scene in Fountain from its scene card and the anchors and beat sheet, sent through the same tool loop and spend guard every other stage uses. A retry is a fresh request, so the journal does not replay a failed answer. An incomplete or empty answer stops the stage. The drafting stage checks each scene and assembles the script, so the model's output is checked before it is stored. Compatible: one new prompt template, pinned and listed; the drafter port takes the try number; no existing behaviour changes.
