The publishing `ReadinessReport` is now `ReleaseReadinessReport`, so it no longer shares a name with the health-check `ReadinessReport`. `engineering_influence.publishing.project_layout` stays as a deprecated shim that re-exports `ProjectLayout` and warns; import it from `engineering_influence.models.publishing.project_layout`. The `ei` command and its output are unchanged.
