One command now installs what a book needs: `install.sh`, run as `curl -fsSL https://raw.githubusercontent.com/adammatthewsteinberger/engineering-influence/main/install.sh | sh`. It installs `uv` if missing and `ei` with the extras a book needs, Ollama and the free local model, the TeX tools the build stage calls, a local SearXNG when Docker is present, and a starter author profile it never writes over, then runs the new `ei doctor --ready`. It supports macOS with Homebrew and Linux with apt-get, takes `--dry-run`, `--skip-model`, `--skip-tex`, `--skip-search`, `--with-claude-skill` and `--version REF`, and has been run for real only as a dry run on macOS; the Linux path is tested against stand-in tools. `ei doctor --ready` answers whether this machine can make a book now: it checks the extras, each build tool, the author profile (`--author-profile`, else `EI_AUTHOR_PROFILE`), the local model and the search, and prints every check in one run. `ei doctor --search` now checks the SearXNG at its default address when nothing is configured and the free local model is in use, because that is the search such a run falls back to. A starter profile (`examples/author-profile.example.toml`) and a Claude Code skill (`examples/claude-code/engineering-influence/SKILL.md`) are included, and `ei serve mcp` with a missing module now names the `mcp` and `runtime` extras.
