Five threat-model gaps are closed. LaTeX output no longer contains control characters other than tab and newline. The TeX tools always run with shell escape off, whatever the environment says. A journal key refuses the separator inside a part, so no two requests can share a digest; ordinary digests are unchanged. When two workers record the same request, the second worker's paid entry is kept for the run's spend, while replay still answers with the first. The injection test now reads every metadata key the documents use, so a new one cannot be missed. Compatible: no stored digest, replay answer or output format changes.
