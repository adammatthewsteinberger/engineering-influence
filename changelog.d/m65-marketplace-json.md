`ei plugins search` can now read a Claude Code `marketplace.json` (a path or an `https://` address ending in `.json`) and lists each plugin with its description, version and where its source says it lives. It reads only name, description, version and source from each entry and ignores every other key; a source is classified (`path`, `github`, `url`, `other`) and printed, never followed. For a marketplace on disk, a `path` source also prints the `ei plugins import` command for that folder. Nothing is fetched, cloned or installed, and `plugins fetch` is unchanged. Entries that cannot be read are counted, not hidden.
