Model exchanges can now be recorded once and replayed in tests. `CassetteReplayTransport` answers an adapter from a cassette in order and refuses any request whose method, path or body differs from the recorded one, so a prompt that changed fails the test instead of replaying a stale answer. `CassetteRecordingTransport` keeps the real exchanges with no headers and every key masked, and `JsonCassetteStore` refuses to save or load a cassette that still looks like it holds a secret. A `paid` test marker is deselected by default and also needs `EI_ALLOW_PAID=1`. No cassette has been recorded yet.
