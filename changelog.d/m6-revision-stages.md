A non-fiction run now edits the draft in three passes before the book is assembled: `revise_structure`, `revise_lines` and `copy_edit`. Each makes one call with no tools for each chapter, in order, from its own prompt, and each reads what the pass before wrote (`structure_NN.md`, `lines_NN.md`, `copy_NN.md`); the book is now assembled from `copy_NN.md`. Structure sees the outline, a line on every other chapter and the chapter's plan, lines sees the voice, and copy sees only the chapter. An edit that is blank, or more than a fifth (structure), a tenth (lines) or a twentieth (copy) longer or shorter than the chapter, is not kept and the chapter passes through unchanged, reported as a tolerated `revision-unchanged` issue; an answer that did not finish stops the stage. A chapter that would not fit the model's window stops the stage before the call. The editing passes mean about five model calls per chapter in all, each counted against the run's budget. Skills can be enabled for each pass. Recorded in ADR 0010; nothing here has run against a live model.
