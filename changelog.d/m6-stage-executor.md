A run's stages can now be done by a model. `ModelStageExecutor` reads the stage's recipe, puts the brief and every earlier answer into the prompt as untrusted text, asks through `AskModel`, and keeps the answer once. An answer that is refused, cut off or empty stops the run and stores nothing, so no later stage is built on it. Non-fiction runs have three stages so far (brief, positioning, outline). The worker still uses the offline placeholder unless `EI_STAGE_EXECUTOR=model` is set with `EI_STAGE_MODEL_PROFILE`, `EI_MODEL_PROFILES` and `EI_MODEL_CATALOG`; with anything missing it refuses to start. Nothing has been run against a live provider.
