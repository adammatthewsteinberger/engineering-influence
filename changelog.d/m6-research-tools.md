The research stage and the model's web tools are built (ADR 0008, slice 3). A model-backed non-fiction run is now brief, positioning, research and outline. The research stage is the first stage with tools: `web_search` (titles and links only) and `fetch_url` (public https pages, returned with their address, title and a SHA-256 of the text). Search uses SearXNG first, through `EI_SEARXNG_URL`, with Brave Search as the backup when `BRAVE_SEARCH_API_KEY` is also set; a run with neither stops at start. `examples/searxng/` runs a free local SearXNG on `127.0.0.1` with the JSON format switched on. `fetch_url` only reads an address the model was shown (in the prompt, a link line of an earlier search, or the address header of an earlier fetch; never an error message or page text), so a hostile page cannot steer it to an address that carries the brief out. A search query can still carry text to the search service, and a page can offer a menu of addresses to pick among, which leaks only a few bits. Everything a tool returns, and the text of a tool's error, is now wrapped in an `<untrusted>` block that it cannot close early, before it is stored or shown to the model. The outline prompt is now version 2 and reads the research notes. Nothing has been run against a live model, SearXNG, Brave or the internet, and the SearXNG container has not been started by the project's tests.
