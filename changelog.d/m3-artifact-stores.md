Added the artifact store. A new port, `ArtifactStoreInterface` (put, get, names), keeps the files a run produces under `run id / name`, and has three implementations: in memory, on a local directory, and in the database for workers that do not share a disk. Artifacts are write-once: storing the same bytes again is accepted and returns the same SHA-256, while different bytes under a used name raise the new `ArtifactConflictError`, so a stage that is not deterministic is caught instead of silently replaced. The directory store writes to a `.part` file and renames it, so a crash never leaves a half-written artifact under its real name, and it resolves symlinks through the path guard so a planted link cannot lead a write outside the store's root. `ArtifactAddress` refuses names that are absolute, climb with `..`, or use backslashes. Nothing uses the store yet.
