The ACX export no longer assumes Amazon's Virtual Voice, which is available only after the author applies for access inside ACX. For each part of the book (the opening credits, each chapter, the closing credits and the retail sample), the `audiobook` stage now writes an audio file as well as the text, read by the narrator named in `EI_NARRATOR`, gated and levelled as the other-store audiobook is. The text stays as the script for Virtual Voice, and the manifest records ACX's rule that unauthorized text-to-speech is prohibited, so the author checks the terms before uploading any audio. Compatible: new output files under `acx/audio/`, two new non-blocking issue codes (`ACX_AUDIO_REJECTED`, `ACX_AUDIO_FAILED`), and the manifest's `narrator` field is replaced by `virtual_voice`, `acx_policy` and `audio` records.
