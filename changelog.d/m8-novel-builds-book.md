A novel run now ends in a built book too. Its plan is brief, story bible, beats, outline, **metadata**, draft, **assemble**, **audit** and **build**. The new `metadata` stage (prompt `novel_metadata`, checked with `MetadataParser`) writes the store listing right after the outline. Assemble builds the manuscript project from the draft's own chapters with `kind = "novel"` and the brief's trim size, and keeps the em and en dashes a novel's prose has (a new `VerbatimDashes`; only non-fiction refuses them). Audit and build are the same stages non-fiction uses. **There are no editing passes for a novel yet**, so the book is built from the draft as written. A scripted novel run, built with the real toolchain, is `tests/toolchain/test_run_builds_book.py`. That test found a real defect: the cover text check refused a back-cover blurb whose first letter overhung the safe area by 0.04 in, so a legitimate book could fail its build over a few pixels; the tolerance is now 0.06 in, still far inside KDP's margin. The rehearsal driver (`tests/smoke_run.py`) now runs the plan of the brief's kind.
