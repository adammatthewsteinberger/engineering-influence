The `Dockerfile` has a `worker-tex` target (M8.5): a worker image with the TeX toolchain a book build calls (LuaLaTeX, latexmk, tex4ebook, pdftoppm, epubcheck, a Java runtime, zip and tidy). The default target is still the slim image the compose stack runs; it now also installs the publishing extra, so it is about 170 MB larger. In the TeX image, a book builds to PDF and EPUB and the EPUB passes epubcheck, with the container's filesystem read-only and every capability dropped. The TeX cache has to point at `/tmp`, which the image sets; `docs/WORKER_IMAGE.md` records what was verified and what was not, including a full book and the CI job for this target.
