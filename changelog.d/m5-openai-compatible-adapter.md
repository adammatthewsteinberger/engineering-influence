Added `OpenAICompatibleModel`, a model adapter for OpenAI and for any server that speaks the Chat Completions shape (Ollama, vLLM, llama.cpp, LM Studio), over plain `httpx`. A blank API key sends no `Authorization` header, so a local server needs no key, and `output_cap_field` selects `max_tokens` or OpenAI's `max_completion_tokens`. The shape has no token-counting endpoint, so `count_tokens` returns an upper bound (the UTF-8 byte length plus a per-message allowance) that over-reserves and is corrected from the server's reported usage. Cached prompt tokens are priced at the cache-read rate. Spent quota (`insufficient_quota` or 402) and refused keys park the run; 408, 429 and 5xx are transient. Nothing calls the adapter yet.
