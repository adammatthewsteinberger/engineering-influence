Added the first versioned contracts. `contracts/brief/v1` holds `BookBriefV1`, the document that starts a book run: a kind (`nonfiction` or `novel`), an idea and a required spending cap in micro-dollars, with an optional title hint, audience, target length, trim size and language; unknown fields, a second schema version and a missing budget are refused. `contracts/book_config/v1` formalises what `BookLoader` reads from `books/<slug>.toml` (`source`, `front`, `parts`, `back`, `not_in_book`, each entry a bare file name or a table with a style), keeps every other key as metadata, and is tested to order a book exactly as the publisher does. Broker messages now carry `schema_version: 1`; a message without it is read as version 1 so messages already queued when a worker upgrades still parse, and any other version is refused. Planned for a later pre-1.0 release, and not part of this change: the public project request will stop taking `PipelineStage` names once `ei book create` replaces them, which will change the REST schema, the SDK and the MCP tool.
