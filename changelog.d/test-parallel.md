The test gate runs in parallel: `pytest-xdist` is in the test extra and the CI test job uses `-n auto`. The whole suite with coverage takes about 154 seconds on eight workers, against about 415 serially, and still reaches 100% coverage. The publishing tests no longer depend on the order they run in, because `pypdf.filters` is imported before any test narrows `PATH`. `docs/TEST_PERFORMANCE.md` records the baseline.
