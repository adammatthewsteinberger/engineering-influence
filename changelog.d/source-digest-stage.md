A screenplay run now condenses its source files before it outlines the film. A new `digest_sources` stage runs first and writes one digest per source file, `digest/NNN.md`: a model condenses each source to about 250 words, keeping its events, named people and places, plot-carrying dialogue and the numbers used later. A digest that is already stored is kept, so a stage that runs again condenses only what is missing. Once a run has digests, the stages that read the sources read the digests instead of the files. The model prompt is `screenplay_digest_source` (version 1). Compatible: the screenplay plan has one more stage at the start, the cost estimate prices it, and no existing command or error code changed. Digests are a model's paraphrase of the source, so an outline built from them is only as faithful as the digest.
