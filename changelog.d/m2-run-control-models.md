Added the first pure models for the 1.0 book pipeline (M2): `BookKind` (nonfiction or novel), `QualityIssue` and `GateVerdict` (what a gate found, with a failed verdict required to say why and a passing one barred from carrying a blocker), `Budget` (a spend cap in integer micro-dollars where a call reserves its worst-case cost first, so spent plus reserved can never pass the cap) and `DegradeLadder` (an ordered list of cheaper fallbacks a run steps down, never back up). They live in `engineering_influence.models`, each with its interface, and nothing uses them yet; the pipeline, the API and the CLI behave as before. A Hypothesis property test checks that no interleaving of reserves, settlements and failed calls can overspend a budget.
