Added `AnthropicModel`, the first model adapter. It calls the Anthropic Messages API over plain `httpx` (ADR 0007), sends the system prompt as a cached block, counts input tokens before a call, and sorts every failure into the three outcomes a run acts on: a rate limit, server error or dropped connection is transient; spent credit or a refused key is a capacity failure that parks the run; anything else stops it. The `runtime` extra now includes `httpx`. Nothing calls the adapter yet.
