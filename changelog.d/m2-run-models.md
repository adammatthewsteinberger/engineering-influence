Added the pure models a book run is built from: `BookBrief` (an idea, a kind of book and a required spending cap, with optional title hint, audience, target length, trim size and language), `StagePlan`, `BookRun` with its `RunStatus` (pending, running, parked for credit, completed, failed, cancelled), `SourceRecord` and `StoryBible`, each with its interface and move-map entry. A run is an immutable value: every change returns a new one, so a repository can store each step and a resumed run picks up where the last stored one stopped. Nothing consumes them yet.
