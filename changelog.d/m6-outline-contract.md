The outline is now a contract (ADR 0010, the first step of drafting chapters). The `stage_outline` template (now version 3) tells the model to write each chapter as `## Chapter N: Title` with `Purpose:`, `Beats:`, `Claims to source:` and `Leads to:`, and a new `OutlineParser` reads that strictly into an `Outline` of `ChapterOutline`s (at most 50 chapters, numbered 1, 2, 3 with no gaps, one-line bounded texts; a model's preamble and a closing paragraph after a blank line are ignored, and hidden and control characters are removed). A check run when the outline stage finishes refuses an answer it cannot read with `OUTLINE_INVALID`, before it is stored, so a malformed outline stops the run at the outline and not after drafting has been paid for. ADR 0010 records the decision to draft chapters in order inside one `draft` stage, and to drop the plan's parallel fan-out and join counter for 1.0, because a rolling summary needs the chapters in order. The drafting stage itself is not built yet. See docs/PROMPTS.md and docs/adr/0010-chapters-are-drafted-in-order-in-one-stage.md.
