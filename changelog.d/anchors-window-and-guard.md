The local model's window is now 131,072 tokens, and the screenplay anchors prompt is version 4. Version 4 names the seven anchor sections and states the All Is Lost rule, with an example, so a local model writes what the format check asks for. A request the model's window cannot hold is now refused before it is sent, with `CONTEXT_TOO_LARGE`, and says how large the prompt is. Before, an oversized prompt was cut in the middle by the server without a word. The estimate uses three characters to a token, the project's fitting constant, so it refuses a little early rather than sending a prompt that does not fit. Compatible: no command or stage changed; the local server must be started with `OLLAMA_CONTEXT_LENGTH=131072` and `OLLAMA_NUM_PARALLEL=1` to offer the full window.
