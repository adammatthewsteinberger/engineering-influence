`ei acp` serves the Agent Client Protocol (stable, version 1) over stdin and stdout, so an editor or agent client can start a book run in a session. `initialize`, `session/new`, `session/prompt` and `session/cancel` are implemented; a prompt is read as the same TOML brief that `ei run create` reads, and it starts the same run. Sessions live in the process, and a run outlives its session. Permission requests, `session/load`, MCP servers and progress streaming are not yet implemented. See [INTERACTIONS.md](docs/INTERACTIONS.md#agent-client-protocol).
