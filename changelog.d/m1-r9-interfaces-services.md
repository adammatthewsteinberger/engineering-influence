Gave every service, controller and repository an interface and made each inherit it: 70 new `…Interface` modules, each beside its class in the layer's `interfaces/` folder (`services/<group>/interfaces/`, `repositories/interfaces/`, `controllers/interfaces/`). They follow the rules set in the previous step: methods only, `__slots__ = ()`, and models, contracts and type aliases imported for type checking only, with annotations and defaults copied verbatim. The two SQLModel ledger and outbox tables inherit theirs too; the tables `create_all()` builds are unchanged, statement for statement. The generated REST schema, the MCP tool list and every `ei` help page are byte-identical.

The interfaces that already existed for `ProjectController`, `DispatchOutbox`, `ProcessJob`, `ReadinessProbe`, `RunPhase` and `StartPipeline` are untouched. Services still construct their own pure helper services (for example `EpubVerifier` builds its checks); passing those in as interfaces is a separate, later change. The 44 classes left without an interface are all in `infrastructure/`, `interactions/` and `runtime/`.
