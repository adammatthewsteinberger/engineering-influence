A screenplay run has its full plan in the code: the brief, the anchors, the beat sheet, the scene cards, and then the drafting of every scene, which the model now writes. The drafting stage is routed for the screenplay kind, takes its title from the brief (UNTITLED when none is given), and the cost estimate prices the drafting at about 180 scenes, one call each, for the three-hour target. A screenplay brief is still refused, because a run cannot yet be built from the novel: the source stage follows. Compatible: the screenplay plan and routing; no existing kind changes.
