The documentation site's navigation is reworked. The top bar had seven groups, and its menus were transparent, so the text of the page showed through their items. It now has five groups (Start, Writing books, Reference, Operating and Project; the separate Quality group is part of Operating). Each menu has a solid background in the colours of the current theme, and a long menu scrolls. The "Edit on GitHub" link is removed: it pointed at `docs/<name>.md`, which is not where the pages come from. Checked in a browser at desktop width in both themes, and pinned by tests.
