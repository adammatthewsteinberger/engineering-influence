Closed several ways for untrusted text to reach TeX live, and added `docs/THREAT_MODEL.md`. A bare URL or link target containing `\`, `{` or `}` could close `\url{` and leave the rest as TeX; a fenced code block containing `\end{verbatim}` could end its environment early; the title, subtitle, author and edition went raw into the PDF info dictionary; and `website` and `email` went raw into `\url` and `\href`. URLs are now percent-encoded, a code block with `\end{verbatim}` and a `website` with a scheme other than http or https are refused with a message, and the PDF info strings drop the characters TeX or PDF would act on (an ordinary title is unchanged, and the page text and EPUB contents of the fixture books are byte-identical before and after). A new tripwire test fills every field with a payload and fails if a live macro reaches the generated TeX, and a new toolchain test builds a hostile book with the real tools and checks that nothing in it runs.
