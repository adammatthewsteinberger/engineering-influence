`ei book package SLUG` writes the KDP release bundle to `build/SLUG/release/kdp` (M8.2): `listing.md` (the listing to paste, with the file table and hashes), `MANIFEST.json`, and a copy of each finished file the release requires. It refuses, writing nothing, when the release check fails, when a required file is missing, or when the listing is outside the release limits. The packaging is a service behind a publisher port, so the controller only coordinates it, and the directory adapter refuses symbolic links and names that are not plain filenames. Nothing is uploaded; KDP has no publishing API.
