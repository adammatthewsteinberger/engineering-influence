The model port can now carry tools. A `ModelRequest` can offer tool definitions and a transcript of earlier tool turns, and a `ModelResponse` can return the tool calls the model asked for with the new `tool_use` stop reason. Both adapters speak their provider's format (content blocks for Anthropic, `tool_calls` and `tool` messages for OpenAI-compatible servers, including local servers that report `stop` alongside a tool call). Adapters never run a tool, and `CallModel` refuses a request with tools until the tool loop and journal exist, so nothing offers tools yet. Not run against a live provider.
