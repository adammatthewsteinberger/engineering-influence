A non-fiction run now ends with an `assemble` stage that turns the drafted chapters into a manuscript the publishing pipeline can read: `manuscript/src/chapter_NN.md` and `manuscript/books/<slug>.toml` in the run's artifacts, with a list in `assemble.md`. It calls no model. Each chapter is headed with the outline's title; em and en dashes, which the typesetter refuses in non-fiction, are rewritten (a dash between digits becomes a hyphen, any other a comma), and an unfinished marker such as `[TODO]` or the word `Draft` stops the stage with the chapter and line. The config has the kind, title, trim size when set and the chapters, and not the author, publisher, edition, year or bio, which the author supplies, so the book loads but does not yet build. Recorded in ADR 0010.
