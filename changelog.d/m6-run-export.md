`ei run export RUN_ID DIRECTORY` writes what a run produced to a new or empty folder: the book as a project at the top (`books/<slug>.toml` and `src/chapter_NN.md`, ready for the book commands) and every other artifact, such as the stage outputs and the audit reports, under `run/`. It only reads the run. Nothing is overwritten, a folder that already holds anything is refused, and either every file is written or none is (the tree is built beside the target and moved into place). Until now a run's manuscript could only be read one artifact at a time through the API.
