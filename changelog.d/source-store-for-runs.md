`ei book create --source DIR` gives a run a folder of source files (`.md` and `.txt`). Each file is read when the run is created, numbered in name order, and kept inside the run as `source/NNN.md` with its SHA-256 digest recorded, so a run never reads the folder again. An empty or missing folder is refused before any money is spent. The run's brief is still refused for screenplays until the drafting stage uses the sources. Compatible: a new optional `--source` flag and a new `SOURCES_NOT_STORED` internal error code for a build that cannot keep sources; existing commands and runs are unchanged.
