The release workflow can rehearse the upload on TestPyPI before PyPI. A new `testpypi` job publishes the same files with trusted publishing and no token, and runs only when the repository variable `PUBLISH_TO_TESTPYPI` is `true`. When it runs, the `pypi` job waits for it and does not run if it failed or was cancelled; when it is skipped, `pypi` goes ahead as before. Neither job has run yet.
