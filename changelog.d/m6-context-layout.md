The prompt that drafts a chapter now keeps everything from outside out of the system part. The context assembler (not yet used by any stage) put the style and the grounding in the high-trust `system` part and left the summaries, the tail and the beats unwrapped, which suited a story bible the product wrote but not a non-fiction book whose grounding holds web research and whose summaries are model output. The `context_pack` template (now version 2) holds fixed system text, and the voice, the book and its sources, the earlier chapters' summaries, the tail of the previous chapter and this chapter's beats are each an untrusted blank, rendered as their own `<untrusted>` block in the prompt with any copy of the tag defused. Only the caller's instruction is plain text, and it must hold nothing from a model or the web. Fitting to a token budget is unchanged. See docs/PROMPTS.md.
