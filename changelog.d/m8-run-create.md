`ei run create BRIEF.TOML` starts a book run from a brief file, and `ei run runs` lists the saved runs (M8.1). The brief is read as TOML and checked against the brief contract, so a file that is not a brief is refused on one line with nothing saved; a kind this build cannot start is refused the same way. The run is saved pending with the brief's cap as its budget, and its first stage is queued on the broker, exactly as `resume` queues one, so the worker does the stages. Nothing here runs a stage in-process, and no API, MCP or SDK method starts a run yet.
