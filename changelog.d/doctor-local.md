`ei doctor --local` checks the free local model (M6.6): that something answers at `EI_LOCAL_URL`, that the model is pulled (naming `ollama pull` if not), one tiny real completion (free, on this machine; an empty reply fails, because a reasoning model can spend its whole cap before it writes), and that the context length Ollama loaded the model with is at least the 32,768 a prompt is assembled to fit (naming `OLLAMA_CONTEXT_LENGTH` if not). A server that is not Ollama passes on its answer alone. Exit 0, 1 or 2 as for the other checks, and it runs on its own, not with `--models` or `--search`. It was run once against a real Ollama; the rest is tested against local fakes.
