Granting and denying a run's request for budget are on the API (`POST /v1/runs/{run_id}/grant` and `/deny`), in MCP (`grant_run`, `deny_run`) and in the SDK (`grant_run`, `deny_run`, sync and async), as well as on the command line. Each refuses exactly what the service refuses. See [INTERACTIONS.md](docs/INTERACTIONS.md#rest-api).
