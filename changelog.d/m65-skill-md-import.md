`ei skills import SOURCE --stage STAGE [--section TITLE ...]` turns a `SKILL.md` (the Vibey and Claude skill format: a `---` frontmatter block and markdown) into an ordinary skill file to review and lock with `ei skills add`. You choose the sections and the stages; nothing is cut to fit, so when the chosen text is longer than a part holds (8,000 characters) the error lists every section with its length. Frontmatter keys other than `name` and `description` (`allowed-tools`, `domains`, and the like) are read, set aside and named, never used, because a skill grants nothing. It writes a new file and never replaces one, reads only the `SKILL.md`, follows no link, and locks and enables nothing. Tests include a real shaped file imported, locked, enabled and read by the research stage's prompt guidance. This is the first step of M6.5 (the model's reach); serving large references on demand comes next. See docs/SKILLS.md.
