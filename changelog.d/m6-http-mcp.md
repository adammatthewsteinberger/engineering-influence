Remote MCP servers over HTTP (ADR 0008, slice 4d). `ei tools add --url URL NAME` contacts a server once and locks its address, the name and version it reported and a hash of its tools; a lock entry has either a `command` or a `url`, and `[server.files]` is only for a command. A remote server is reached over Streamable HTTP, https only and only to a public address (the URL policy `fetch_url` uses, asked before every request), with no redirects, no cookies, no compression, replies bounded to 4 MiB, 128 messages and 30 seconds, and a four-hour session. A token is the variable named by `--bearer-env`, sent as a bearer header to the locked address and never written into the lock or an error; a lock refuses a user, query string or fragment in the address. A remote server is a weaker pin than a local one, because its code is not ours to hash: only its address and what it advertises are locked. A server on this machine or network cannot be reached over HTTP; use stdio. The name is resolved twice (the policy, then the connection), the same gap as `fetch_url`. See docs/TOOL_LOCK.md.
