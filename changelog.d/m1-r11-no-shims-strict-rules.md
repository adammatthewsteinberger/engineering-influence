**Breaking:** removed the `engineering_influence.publishing` package. Its sixteen cover modules (`engineering_influence.publishing.covers.{box, box_blur, compositing, cover_builder, cover_layout, cover_painter, cover_plugin, cover_plugin_loader, cover_style, film_grain, ink, painter_registry, quiet_zone, soft_rect, starfield, value_noise}`) and `engineering_influence.publishing.project_layout` were compatibility shims that warned and re-exported the real classes; they are gone, with no deprecation period. Import the same names from `engineering_influence.covers` (`CoverPainter`, `CoverPlugin` and `ProjectLayout` are there too). They are the same classes, so a private cover plugin only needs its import lines changed; one that loaded 16 lines across three files from the old paths loads again, with all its styles, once they point at `engineering_influence.covers`.

Every architecture rule in `tests/architecture/` now holds with no exceptions, so the tolerance file that allowed a fixed number of violations (`ratchet.json`) and its update switch are removed. `test_rules.py` asserts that each of the nine rules has zero violations everywhere, and that none has been dropped from the metrics: a class without an interface, an import that crosses layers, a file outside the layers or an interface that breaks the declaration rules fails the build. The generated REST schema, the MCP tool list and every `ei` help page are byte-identical.
